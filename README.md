## Overview

Modern exploratory robots and Artificial Intelligence systems are heavily limited by visible-spectrum cameras, high energy consumption, and static pre-trained neural networks that fail when encountering unknown environments or undiscovered species. 

This repository contains the official research concept paper and Python simulation (`Wave_Sensing_Camouflage_Agent.py`) for a unified cognitive-physical robotics architecture. By pairing a **Subtle Neuromorphic Chip** with a **Biomimetic Subtle Body**, the agent moves beyond the visual limitations of the human occipital lobe using long-range wave sensing, achieves stealth through psychological **Inattentional Blindness**, and turns unknown discoveries into intrinsic **Curiosity Rewards**.

---

## Core Architectural Pillars

1. **Beyond the Occipital Lobe (Long-Range Wave Sensing):** Replaces optical cameras with active and passive acoustic/radio wave transceivers inspired by biological echolocation to map pitch-black deep-sea environments without artificial spotlights.
2. **Cognitive Camouflage via Induced Inattentional Blindness:** Instead of expensive physical invisibility, the robot mimics natural ocean current micro-movements and ambient baselines so surrounding marine organisms neurologically filter it out as mundane background noise.
3. **Subtle Neuromorphic Chip & Event-Driven Sensing:** Consumes near-zero power during dormant passive listening phases and triggers wave pulses strictly when hydrodynamic shifts occur.
4. **Curiosity-Driven Continual Learning:** Connects directly to our foundational AGI **Importance Gate** formula:
   \[\text{Memory Importance} = \vert{}\text{Expected Wave Pattern} - \text{Actual Wave Pattern}\vert{} \times \text{Novelty Intensity}\]
   Unknown species trigger high intrinsic **Curiosity Rewards (+Reward)** and dynamic neurogenesis rather than classification errors.

## Experimental Simulation Results

Running `Wave_Sensing_Camouflage_Agent.py` simulates a 100-step autonomous deep-sea mission in total darkness:

* **Ultra-Low Energy Conservation:** Retains **~86% battery energy** after 100 operational steps via event-driven wave sensing.
* **Autonomous Novel Species Discovery:** Detects three rare undiscovered species (Steps 15, 45, and 78) with Importance Gate spikes exceeding `22.0`, raising the cumulative Curiosity Discovery Score to `85.5`.
* **Zero Stealth Breaches:** Maintains natural drift thresholds across all 100 steps, preserving Inattentional Blindness.
* **Memory Bloat Prevention:** Offline sleep pruning every 20 steps keeps consolidated Long-Term Memory strictly bounded at **5 unique nodes**.

## How to Run the Simulation

### Prerequisites
Make sure you have Python installed along with `numpy` and `matplotlib`:

```bash
pip install numpy matplotlib
```

### Execution
Clone the repository and run the simulation script:

```bash
git clone https://github.com
cd Cognitive-Camouflage-Wave-Sensing-AGI
python Wave_Sensing_Camouflage_Agent.py
```
