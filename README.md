## 📖 Overview

Traditional deep-sea robots rely on visible-spectrum cameras, high-energy propulsion, and static pre-trained neural networks—all of which fail in pitch-black environments or when encountering unknown marine species. 

Building upon the foundational framework **[Emotion-Guided, Low-Energy Continual Learning Architecture for Artificial General Intelligence (AGI)](https://github.com)**, this project unifies an energy-conserving cognitive brain with a **biomimetic, non-visual sensory body**. Instead of fragile optical metamaterials, the agent achieves **Cognitive Camouflage** by exploiting biological *Inattentional Blindness*, perceives 3D surroundings through **event-driven acoustic/radio wave sensing**, and converts Out-of-Distribution (OOD) encounters into **intrinsic curiosity rewards** for continual learning.

## 🧠 Core Architectural Pillars

1. **Beyond the Occipital Lobe (Long-Range Wave Perception):**
   Replaces optical cameras with bio-inspired active and passive acoustic/radio wave transceivers. Returning wave echoes map density, size, internal structure, and motion in complete darkness without disturbing ecosystems with artificial spotlights.
2. **Cognitive Camouflage via Induced Inattentional Blindness:**
   Rather than physical transparency, the subtle micro-engineered body mimics natural ocean current drift speeds and ambient thermal/acoustic baselines. Nearby marine organisms neurologically filter out the robot as mundane background noise.
3. **The Subtle Neuromorphic Chip (Event-Driven Sensing):**
   Powered by spiking neural networks (SNNs) and in-memory computing, the **Subtle Chip** remains in a near-zero-power dormant state until passive sensors detect hydrodynamic ripples.
4. **Curiosity-Driven Continual Learning & Sleep Pruning:**
   Unknown biological signatures trigger a high prediction-error spike rather than a classification failure:
   $$\text{Memory Importance} = |\text{Expected Wave Pattern} - \text{Actual Wave Pattern}| \times \text{Novelty Intensity}$$
   High novelty generates an intrinsic `+Reward`, triggering dynamic neurogenesis to permanently store new species while periodic **offline sleep pruning** purges trivial background data to prevent memory bloat.

## 🛠️ Installation & Usage

### Prerequisites
* Python 3.8+
* Standard scientific computing libraries (`numpy`, `matplotlib`)

### Running the Simulation
1. Clone the repository:
   ```bash
   git clone https://github.com.git
   cd Cognitive-Camouflage-Wave-Sensing-AGI
   ```
2. Install dependencies:
   ```bash
   pip install numpy matplotlib
   ```
3. Run the autonomous agent simulation (`100` deep-sea mission time steps):
   ```bash
   python Wave_Sensing_Camouflage_Agent.py
   ```
